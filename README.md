## What counts as "free"

To make this list, a resource must be:

1. **Truly free** — no credit card, no "free trial," no upsell required to download
2. **No email gate** — printables download directly, without forcing newsletter signup
3. **Print-ready** — actual PDF or high-resolution PNG, not a thumbnail teaser
4. **Personal use allowed** — license permits home / classroom / family use
5. **Active** — site has been updated within the last 2 years

Resources behind email gates are listed separately and clearly marked `📧 email required`.

## Contributing

Found a resource that fits the [criteria](#what-counts-as-free)? Open a pull request or [issue](https://github.com/KatherineGuoGuo/analogbag-open/issues).

**Submission format:**

```markdown
- **[Site Name](https://example.com/specific-page)** — One-line description.
  Mark `📧 email required` if signup is required.
```

**Not accepted:**

- Sites that require credit card or paid subscription to download
- Pinterest pin pages (link to the original source instead)
- AI-generated coloring page farms
- Dead links / sites inactive >2 years
